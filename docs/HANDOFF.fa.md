# استودیو محتوا — وضعیت پروژه

سرویسی برای تولید و ویرایش محتوای شبکه‌های اجتماعی با هوش مصنوعی: عکس، ویدیوی کوتاه و افکت‌ها.

## الان چه کار می‌کند (نسخه‌ی ۰.۱)
- آپلود عکس (JPEG، PNG یا WebP، تا ۲۰ مگابایت)
- تبدیل عکس به قالب‌های شبکه‌های اجتماعی: پست مربعی ۱:۱، پست عمودی ۴:۵، استوری و ریلز ۹:۱۶، افقی ۱۶:۹
- سه حالت جای‌گیری: برش هوشمند (روی سوژه‌ی اصلی)، حاشیه‌ی رنگی، پس‌زمینه‌ی محو از خود عکس
- پیش‌نمایش زنده قبل از ساخت، پردازش در صف و دانلود نتیجه
- رابط فارسی و انگلیسی، مناسب موبایل و تم تیره

## اجرا روی سیستم توسعه
```
docker compose up -d
npm install
npm run dev
```
بعد آدرس http://localhost:3100 را باز کنید. اگر فایل `.env` نیست، از روی `.env.example` کپی کنید.

## قدم‌های بعدی
1. حساب کاربری و اعتبار ماهانه
2. ابزارهای هوش مصنوعی برای عکس: حذف پس‌زمینه، ساخت و ویرایش با متن، افزایش کیفیت
3. ذخیره‌سازی ابری (S3 یا R2)
4. ویدیوی کوتاه: برش، تبدیل به ۹:۱۶، زیرنویس خودکار فارسی و انگلیسی

## سؤال‌های باز
- بازار هدف کجاست: کاربران فارسی‌زبان یا ایران، یا جهانی؟ (روی درگاه پرداخت و محل سرور اثر دارد.)
- حساب پرداخت خارجی برای سرویس‌های هوش مصنوعی و سرور در دسترس است؟
